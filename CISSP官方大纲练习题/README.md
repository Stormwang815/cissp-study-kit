# CISSP 官方大纲练习题

来源 PDF：`CISSP-Exam-Outline-May-2021-Chinese.pdf`

注意：文件名包含 2021，但 PDF 首页显示生效日期为 2024-04-15。

生成规则：
- 按 CISSP 8 大领域分类。
- 将 PDF 中编号能力点及列出的关键字/知识点整理为覆盖矩阵。
- 每个关键字/知识点生成 3 道原创练习题。
- 每题包含答案、中文解析、干扰项解释和 CISSP 管理者思维提示。
- JSON 字段兼容之前 App 题库 schema，并额外保留 `chapter_id`、`chapter_name`、`topic_name`。

统计：
- 知识点数量：508
- 每个知识点题数：3
- 总题数：1524

文件：
- `cissp_official_outline_questions.json`：App 可导入题库。
- `coverage_matrix.csv`：知识点覆盖矩阵。
- `summary.json`：生成摘要。
