# 原创 CISSP 题目工作流

## 1. 先选 Domain 和知识点

示例：
- Domain：D5 Identity and Access Management
- 标签：least privilege, RBAC, privileged access
- 考点：最小权限与职责分离

## 2. 写场景，而不是写定义

较弱题型：
- What is least privilege?

较好题型：
- A database administrator requests broad production access to troubleshoot an urgent issue. What should the security manager ensure first?

## 3. 每个选项都要有诱惑性

CISSP 常见干扰项：
- 技术上可行但治理顺序错误
- 过度激进，比如立即关停
- 过度消极，比如直接接受风险
- 把安全团队当成业务风险 owner
- 跳过 policy、approval、business impact、risk assessment

## 4. 解析必须解释四件事

- 正确答案为什么对
- 其他选项为什么错
- 题目考哪个知识点
- CISSP 管理者思维是什么

## 5. 本地 App 推荐字段

- 原题英文
- 中文翻译
- 四个选项
- 正确答案
- 中文详细解析
- 每个错误选项的解释
- Domain
- tags
- difficulty
- source_type
- review_status

## 6. 质量检查清单

- 是否只考一个主知识点？
- 是否存在两个都明显正确的答案？
- 是否有一个最符合 CISSP 管理者视角的答案？
- 是否避免了真实考试题或 dumps？
- 解析是否能让你下次遇到同类题做对？
